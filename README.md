# Network Engineer Portfolio

A responsive, static portfolio website built with plain HTML, CSS, and JavaScript. It can be hosted free with GitHub Pages.

## 1. Personalize before publishing

Search the project files for these placeholders and replace them:

- `[Your Name]`
- `YOUR_EMAIL@example.com`
- `YOUR-LINKEDIN`
- `YOUR-CREDLY`

Also:
- Add your actual résumé PDF if you want a résumé download link.
- Add links to real articles, project pages, and credential profiles.
- Check each project description carefully. Keep only tasks you personally performed and can discuss in an interview.
- Add sanitized diagrams or screenshots if you have permission to share them. Never publish client names, internal IPs, hostnames, credentials, or confidential designs.
- Confirm the exact XE300 product name before publishing it.

## 2. Preview locally

Open `index.html` in a browser. No build step or package installation is required.

## 3. Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository, for example `network-engineer-portfolio`.
2. Upload `index.html`, the `assets` folder, and this `README.md` to the repository root. Do not upload only the ZIP file.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for the Pages deployment to finish. Your site will be available at a URL similar to `https://YOUR-USERNAME.github.io/network-engineer-portfolio/`.

## Notes

- This is a static website; it does not require Netlify or a paid hosting plan.
- The contact button uses a `mailto:` link. Replace the placeholder email with your real professional email.
- The project cards and article cards are starter content, not links to full detail pages yet.
